# UX and Accessibility Learnings

- Ensuring complete meta tags (`twitter:card` using `name` instead of `property`, `theme-color`) improves the branded experience across different platforms, including Twitter previews and browser toolbars on mobile devices.
- Generating and specifying `apple-touch-icon` and Android app manifest (`site.webmanifest`) improves the user experience when saving the site to the home screen of mobile devices.
- Adding descriptive `og:image:alt` provides alternative text for screen readers consuming open graph content.
